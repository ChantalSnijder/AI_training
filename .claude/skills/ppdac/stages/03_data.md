# Stage 3 — Data

Goal: execute the plan's transformations with checks, and leave an audit trail that a colleague can rerun.

## Explore

1. Read `01_problem.md` and `02_plan.md`. The plan is the spec. Deviations require a question.
2. Confirm `checks/checks.py` covers every check in the plan; extend it if not.

## Plan: interview only for surprises (choice questions)

Questions here are **generated from what you find**, not templated; use `AskUserQuestion` with the options and a default. Ask only when a decision changes a number and the plan does not cover it. Always with a default:

- "3.1% of return lines have no matching order. Default: flag and exclude, reported here. Drop, keep or flag?"
- "`status` has 4 values not in the plan (`REFUNDED`, …). Default: map to <…>. Correct?"
- "Duplicate rows on the declared grain: 212. Default: keep first by <timestamp>. Correct?"

Everything else: apply the plan, log the decision.

## Code

1. Run the pilot subset first if the plan defines one. Show checks. Then the full run.
2. `src/03_clean.py`: linear, one function per transformation, each returning a new DataFrame (no in-place mutation), each logging `step | rows_in | rows_out | note`.
3. After every join: assert cardinality and row count. After every filter: log what was removed and why.
4. Write outputs to `data/processed/`. Never touch `data/raw/`.
5. Run reconciliation. Show the delta. If it exceeds tolerance: stop, report, ask. Do not adjust the tolerance.
6. Figures (8+ expected) to `outputs/figures/03_*.png`: row-count waterfall per step; before/after distribution of every measure touched; null rate before/after per column; join match/unmatched by segment; what each filter removed, over time and by segment; duplicates removed, on a map or over time; reconciliation delta by segment; final dataset overview (distribution grid, correlation matrix).
7. Ensure `python run.py` reproduces `data/processed/` from `data/raw/`.
